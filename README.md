# SPLITRIDE（ドライブ精算）

自分の車で友人と遠出したときの交通費を、乗車区間に応じて按分するWebアプリです。
`index.html` 1ファイルだけで動きます（ビルド不要）。スマホのブラウザでも使えます。

## 公開手順（GitHub Pages）

1. 新しいリポジトリを作り、`index.html` と `.gitignore` をアップロードします
2. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存します
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

## できること

- 出発・経由・帰着の地点を、地図のタップまたは場所検索で指定すると、道路距離を各区間に自動入力します
- メーター実測の総距離を入れると、区間距離をその比率で補正します
- ETC利用照会サービスの利用明細CSVを読み込み、旅行分の行を選んで区間に割り当てます
- 燃料代・通行料金・その他の費用を、乗車区間に応じて同乗者に按分し、100円単位で切り上げて請求額を出します

## 個人情報の扱い

- ETC明細CSVは、ブラウザ内だけで処理され、サーバーには送信されません。リポジトリにも含めないでください（`.gitignore` で `*.csv` を除外しています）
- 外部に送るのは、地図の表示範囲に応じたタイル取得、経路検索の座標、「検索」を押したときの検索語だけです

## 利用している外部サービス

| 用途 | サービス | 備考 |
| --- | --- | --- |
| 地図タイル | 国土地理院（地理院タイル） | 出典の表示が必要です |
| 経路距離 | OSRM（FOSSGISの公開サーバー。失敗時はOSRMのデモサーバー） | 無料・キー不要。毎秒1回まで、ベストエフォート |
| 場所検索 | Nominatim（OpenStreetMap） | 入力中の自動検索は禁止のため、「検索」を押したときだけ送信します |

データは © OpenStreetMap contributors（ODbL）です。公開サーバーは予告なく止まったり制限されたりすることがあります。経路距離を取得できない場合も、距離は手入力できます。
